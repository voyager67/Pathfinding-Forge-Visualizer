How to read the grid

Explored cells show where the algorithm has searched. Frontier cells are discovered but not yet processed. The yellow route is the final path when one exists.

BFS and Dijkstra find shortest paths on this equal-cost grid. A* uses a distance heuristic. DFS finds a route when one exists, but does not guarantee the shortest.
