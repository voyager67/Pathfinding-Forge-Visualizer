# Browser Test Checklist

This file is a checklist, not a claim that every item has passed on every browser. Record browser/version and results before publishing a formal test report.

- [ ] Page loads with CSS and JavaScript assets
- [ ] Grid renders at each density setting
- [ ] Draw-wall and erase tools work with pointer input
- [ ] Start and finish nodes can be moved to valid cells
- [ ] BFS finds a shortest path on an unweighted grid
- [ ] Dijkstra finds a shortest path with the current equal-cost edges
- [ ] A* finds a shortest path with the supported movement heuristic
- [ ] DFS can find a path when one exists; no shortest-path guarantee is asserted
- [ ] Unreachable destination reports no path
- [ ] Play, pause, step, reset, and speed controls behave correctly
- [ ] Random maze and clear-board controls work
- [ ] Four-way and eight-way movement work as intended
- [ ] Layout remains usable on mobile and desktop
- [ ] Browser console has no errors
