# Contributing to Pathfinding Forge

Thanks for your interest in improving Pathfinding Forge!

## Before opening an issue
- Check whether the issue has already been reported.
- Include your browser and operating system.
- Describe the exact steps to reproduce the problem.

## Pull requests
- Keep changes focused and explain the reason for the change.
- Test clear paths, blocked paths, reset behavior, and each affected algorithm.
- Do not claim that an algorithm guarantees a shortest path unless its conditions are satisfied.
- Update the README when user-facing behavior changes.

## Development
This is a static HTML/CSS/JavaScript project. Open `index.html` in a modern browser or serve the folder with a local HTTP server. No package installation is required.
